# Console Shooting Game

Windows 콘솔 창에서 아스키 문자로 동작하는 **종스크롤 슈팅 게임**입니다.

고등학교에서 C/C++를 처음 배우면서 만든 첫 프로젝트로, 배운 문법을 실제로 굴려보기 위해
클래스 상속·가상 함수·상태 패턴(State Pattern)까지 직접 구현해 본 결과물입니다.

> 개발 시점: 2018년 · 언어: C++ · 환경: Visual Studio (Win32 콘솔)

---

## 게임 소개

플레이어는 화면 하단의 기체를 조종해 위에서 내려오는 몬스터를 처치합니다.
점수를 쌓으면 스테이지가 올라가고, 최종적으로 **2페이즈 보스**를 잡으면 게임 클리어입니다.

- 4종의 히어로 (체력 / 탄약 / 연사 속도 / 스킬 보유량이 각각 다름)
- 3종의 액티브 스킬 (레이저 · 폭탄 · 실드)
- 5단계 스테이지 + 보스전
- 상점에서 코인으로 히어로 해금 및 코인 획득량 2배 구매
- 탄약 / 재장전 / 아이템 / 장애물(Barrier) / 터렛 소환 등의 시스템

## 실행 방법

```
2018_06_12_02_State/console.sln  →  Visual Studio로 열고 빌드 & 실행 (Win32)
```

- 구성: Win32 콘솔 애플리케이션 (MultiByte 문자셋)
- 별도 외부 라이브러리 없이 `ConsoleEx3` (콘솔 렌더링 래퍼)만 함께 빌드됩니다.

## 조작법

### 게임 플레이

| 키 | 동작 |
|---|---|
| `↑` `↓` `←` `→` | 기체 이동 |
| `Space` | 사격 |
| `B` | 스킬 1 — RAZER (화면 가로 전체를 덮은 채 위로 훑고 올라가는 레이저) |
| `V` | 스킬 2 — BOMB (기체 전방으로 폭탄 발사) |
| `C` | 스킬 3 — SHIELD (10초간 무적) |
| `Z` | 터렛 설치 (TERRET 히어로 전용) |
| `P` / `O` | 일시정지 / 해제 |

### 메뉴 조작

| 화면 | 키 |
|---|---|
| 로고 | 아무 키나 입력 |
| 메인 메뉴 | `↑` `↓` 이동, `Space` 선택 |
| 히어로 선택 | `←` `→` 이동, `Tab` 확정 |
| 상점 | `↑` `↓` 이동, `Tab` 구매 |
| 게임 오버 | `R` 재시작, `Tab` 히어로 다시 선택 |
| 클리어 | `H` 메뉴로 돌아가기 |

## 히어로

| 히어로 | 체력 | 탄약 | 재장전 | 연사 간격 | 레이저 / 폭탄 / 실드 | 특징 |
|---|---|---|---|---|---|---|
| **NORMAL** | 30 | 500 | 5.0s | 48ms | 3 / 3 / 2 | 밸런스형 기본 기체 |
| **SMG** | 30 | 200 | 2.0s | 35ms | 3 / 1 / 5 | 빠른 연사 · 짧은 재장전 |
| **DG** | 20 | 500 | 5.0s | 300ms | 3 / 2 / 2 | 한 발에 5갈래로 퍼지는 산탄 |
| **TERRET** | 25 | 100 | 2.0s | 45ms | 2 / 2 / 7 | `Z`로 자동 사격 터렛 설치 |

> 상점에 히어로 해금 기능이 구현되어 있지만, 현재 빌드에서는 테스트 편의를 위해
> 모든 히어로가 처음부터 선택 가능하도록 되어 있습니다.

## 스테이지 구성

| 스테이지 | 진입 조건 | 내용 |
|---|---|---|
| 1 | 시작 | 기본 몬스터 |
| 2 | 5,000점 | 몬스터 증가 |
| 3 | 15,000점 | 장애물 · 서브 몬스터 등장 |
| 4 | 40,000점 | **보스 1페이즈** (HP 150) |
| 5 | 보스 1페이즈 격파 | **보스 2페이즈** (HP 300, 보스 스킬 추가) |

2페이즈 보스까지 격파하면 `Game Complete` 화면과 함께 최종 점수가 표시됩니다.

## 프로젝트 구조

```
2018_06_12_02_State/
├─ console.sln
├─ ConsoleEx3/            # 콘솔 렌더링 래퍼 (더블 버퍼 출력, 키 입력, 타이머)
│  ├─ ConWrap.cpp/.h
│  └─ SysTimer.cpp/.h
└─ console/               # 게임 본체
   ├─ main.cpp            # 진입점 · 스프라이트 데이터
   ├─ Mng.cpp/.h          # 전역 매니저 (State 등록)
   ├─ State.h             # 상태 인터페이스 (추상 클래스)
   ├─ StateCtrl.cpp/.h    # 상태 전환 컨트롤러
   ├─ LogoState / MenuState / HeroPickState
   ├─ GameState           # 게임 루프 (충돌·스테이지·스킬 처리)
   ├─ ShopState / ResultState / FinishState
   ├─ Unit.cpp/.h         # 모든 오브젝트의 베이스 클래스
   ├─ Hero / Bullet / Monster / SubMonster / Boss / BossSkill
   ├─ Skill / Effect / Item / Barrier / Terret
   ├─ Ui.cpp/.h           # HUD (점수·시간·탄약·스킬 쿨다운)

```

## 구현하면서 배운 것

- **상태 패턴** — `CState` 추상 클래스를 상속받은 각 화면을 `CStateCtrl`이 등록·전환하도록 만들어, 화면 전환 로직을 게임 로직에서 분리했습니다.
- **상속과 가상 함수** — 히어로·총알·몬스터·아이템 등 모든 오브젝트를 `CUnit`에서 파생시키고 `Update()` / `Draw()` / `Clipping()`을 오버라이드하는 구조로 통일했습니다.
- **오브젝트 풀링** — `new`/`delete` 대신 고정 크기 배열(`D_BULLET_MAX` 등)과 `m_bUse` 플래그로 오브젝트를 재사용했습니다.
- **`GetTickCount()` 기반 타이머** — 연사 간격, 재장전, 스킬 쿨다운, 몬스터 스폰 주기를 프레임이 아닌 실제 경과 시간으로 제어했습니다.
- **더블 버퍼링** — 백버퍼에 그린 뒤 `Flip()`으로 한 번에 출력해 콘솔 깜빡임을 없앴습니다.
